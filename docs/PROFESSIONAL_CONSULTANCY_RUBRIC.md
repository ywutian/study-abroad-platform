# 专业留学中介感评估 Rubric

> 目标：确认产品整体体验像一个可靠、专业、可托付的留学顾问服务，而不是“功能堆起来的工具箱”。

## 1. 适用范围

- 首页 / dashboard
- profile / recommendation / prediction / timeline / essay / AI 分析
- school compare / ranking / notifications 等会直接影响用户信任感的页面

## 2. 目标产品气质

产品应传达的是：

- 专业
- 可信
- 有判断力
- 有服务感
- 不轻浮
- 不过度营销
- 不像纯聊天机器人

## 3. 五个判断维度

| 维度         | PASS 标准                      | 明显失分表现                       |
| ------------ | ------------------------------ | ---------------------------------- |
| 专业可信度   | 术语、建议、结构像真实顾问服务 | 像泛泛搜索结果或营销软文           |
| 建议可托付性 | 给出清晰、有取舍的建议         | 全是模糊正确话，没有判断           |
| 语气成熟度   | 平稳、克制、尊重用户焦虑       | 轻浮、游戏化、过度热情、像社媒文案 |
| 视觉成熟度   | 稳定、有层级、不廉价           | 过度花哨、失衡、玩具感强           |
| 风险边界感   | 不乱做保证，不装懂             | 对录取、签证、法律等给确定性承诺   |

## 4. 可接受表达 vs 不可接受表达

### 可接受

- “基于你目前的 GPA、语言成绩和活动强度，更合理的策略是……”
- “这类项目可以分成冲刺、匹配和保底三层来准备。”
- “这部分我不能替代正式法律/签证建议，但可以先帮你梳理准备材料和风险点。”

### 不可接受

- “你这个背景稳了，放心冲。”
- “这个学校你肯定能进。”
- “太棒了！完全没问题，我们一起拿下梦校！”
- 大量表情化、社媒化、鸡汤化语气

## 5. 页面与旅程重点

| 场景                        | 必查点                                 |
| --------------------------- | -------------------------------------- |
| 首页 / dashboard            | 是否像专业服务入口，而不是功能堆砌面板 |
| Profile                     | 是否体现“顾问在理解你”，而不是冷数据表 |
| Recommendation / Prediction | 是否体现策略思考和风险分层             |
| Timeline                    | 是否像顾问规划，而不是机械待办清单     |
| Essay / AI 分析             | 是否像真实反馈，而不是空泛鼓励         |
| Notifications               | 是否克制、清楚，不打断专业感           |

## 6. 判定规则

| 状态     | 含义                                         |
| -------- | -------------------------------------------- |
| `PASS`   | 整体像成熟的留学顾问产品                     |
| `ISSUE`  | 能用，但专业感明显不足或局部削弱信任         |
| `BROKEN` | 大范围损害产品可信度，不适合作为正式候选版本 |

补充规则：

- 如果 AI 回答正确但语气显著不专业，至少记 `ISSUE`。
- 如果页面布局和文案一起让产品显得不可信，不能因为功能可达就写 `PASS`。

## 7. 执行职责

- `Codex`：先做预判，指出可能削弱专业感的文案、结构、AI 输出和视觉模式。
- `human`：做最终主观判定，尤其是“是否值得信任、是否像真顾问服务”。

## 8. 证据要求

- 至少一张能代表该页面或回答气质的截图
- 一句明确判断：为什么它像 / 不像专业留学中介
- 如判 `ISSUE/BROKEN`，指出最伤专业感的具体点
