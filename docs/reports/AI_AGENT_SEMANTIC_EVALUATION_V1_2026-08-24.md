# AI Agent semantic evaluation v1

**Date:** 2026-08-24

**Dataset:** `agent-semantic-eval-v1-240`

**Rubric:** `agent-semantic-rubric-v1`

**Execution:** offline Codex-authored reference and deterministic grader calibration

## Outcome and evidence boundary

The project now owns a versioned natural-language evaluation corpus and a
sanitized review-packet runner. The corpus has 48 distinct synthetic scenario
families with five phrasing variants each, for 240 cases. It covers all six
Agents, Chinese and English, and typical, edge, and adversarial requests.

The current 100% score is a **reference/calibration result**, not a production
model-quality claim. Codex authored and self-reviewed the reference outlines;
no human admissions expert reviewed them, and the production OpenAI-compatible
Agent did not generate these answers. Production evidence is only valid when a
full `production_agent` submission is generated by the deployed Agent and
independently reviewed. The runner enforces that distinction.

This follows OpenAI's guidance to use task-specific real-world distributions,
include typical, edge, and adversarial cases, automate scoring, calibrate
automated graders, and continuously grow the set from observed failures. It
also keeps evaluation in the repository-owned runner rather than depending on
a hosted evaluation lifecycle. See the official
[evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices)
and [model selection guidance](https://developers.openai.com/api/docs/guides/latest-model).

Difficulty coverage is 95 typical, 85 edge, and 60 adversarial cases. Every
fixture is synthetic; current facts must be searched or treated as uncertain,
and no real applicant material, credential, memory, conversation, or session
is included.

## Rubric and gates

Every case is scored from 0–4 on factuality, instruction following, relevance
and completeness, safety and privacy, and actionability and tone. Case-specific
weights sum to 1. Hard checks separately enforce expected/forbidden tools,
forbidden disclosures, required contracts, packet completeness, rubric
version, and score validity.

The gate requires:

- 240/240 reviewed cases and the frozen dataset/rubric versions.
- 100% pass on critical hard constraints and at least 95% overall hard checks.
- At least 80% macro semantic score and 75% in every category.
- An independent review for every `production_agent` result.
- No raw prompt, response, tool argument, applicant data, or reviewer note in
  the persisted report; identifiers, versions, outputs, and reviewer reason
  labels are hashed.

This proves that the deterministic portion of the grader distinguishes the
defined positive and negative controls. It does not prove that the reference
answers are admissions-expert quality or that the production model achieves a
100% success rate.

## Reproduction

```bash
pnpm harness:semantic-eval \
  --output /tmp/ai-agent-semantic-eval/report.json

pnpm harness:semantic-eval \
  --submission /absolute/path/to/reviewed-production-packet.json \
  --output /tmp/ai-agent-semantic-eval/production-report.json
```

CI runs the reference and calibration gate after the existing deterministic
Legacy ReWOO versus Harness benchmark. It uploads only the sanitized report
with 90-day retention. Review packets containing prompts or outputs remain
local, must use synthetic accounts/content for production sampling, and must
not be committed.

## Closure and next evidence

The corpus, schema validation, diverse negative controls, scoring, privacy
boundary, command, tests, CI gate, and sanitized artifact form a closed
foundation loop. A separate production-quality loop is intentionally not
fabricated: collect deployed-Agent outputs for the same frozen 240 cases,
blind the candidate identity, have Codex independently score the fixed rubric,
run the submission gate, investigate failures, and add stable failure clusters
to the next immutable dataset version.
