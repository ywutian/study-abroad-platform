## 一、预计结论（一页读懂）

| 问题 | 2026 年末预计结果 |
|------|-------------------|
| 产品是否以 **Gemini Vision** 跑 PDF/截图？ | **否**（主路径仍为文本；Vision 生产校数 **0**） |
| PDF 怎么进模型？ | **不进入 Vision**；ETL 仍为 **pdftotext → 文本 LLM** |
| 线上主 LLM | **OpenAI 文本 API**，默认 **gpt-4o-mini** |
| 录取概率从哪来？ | **counselor 规则引擎**（可审计），**不是** LLM/Vision 出数 |
| 能否对外说「预测准确率 X%」？ | **否**（verified outcome 预计仍 **<50**） |
| 240 校数据会怎样？ | 仍全覆盖必填字段；启发式校 **~55–60%**；Tier1 CDS 分格 **~12–18 校** |
| CDS 文本抽取「作业成功」？ | **~80–84%**（非字段真值准确率） |
| 用户能否上传截图问 AI？ | **预计仍不能**（仅存储，不进多模态模型） |
| 作品集/艺术校 AI 评估？ | **不做**；维持「无标化概率 + 说明文案」 |
| 研发期 Claude Code / Codex | 继续用于**写代码、跑 batch**；**不等于**产品 Vision |

**一句话预计**：2026 年末的 Lumni 仍是 **「可审计规则预测 + 文本 LLM 顾问 + 文本化学校数据 ETL」** 平台，**不是** 「Gemini Vision 驱动的多模态录取引擎」。

### 3.2 PDF / 截图 / 文档理解

| 项目 | 2026-05 现状 | **2026-12 预计** |
|------|--------------|------------------|
| 批量 CDS：直接传图到 Gemini | 无 | **无** |
| 批量 CDS：PDF 渲染页图再送 Gemini | 无 | **无** |
| 批量 CDS：pdftotext → 文本 LLM | 是 | **是（主路径）** |
| 批量 CDS：regex 优先、LLM 兜底 | 是 | **是** |
| 用户聊天发图 → AI 理解 | 否 | **否** |
| 认证材料 → Vision OCR | 否 | **否**（仍人工审核为主） |
| 简历 PDF | pdf-parse + 文本 | **不变** |
| closure-agents 硬编码调研 | 有 | **部分改为 JSON artifact**（若做数据治理） |

**预计 PDF 入模路径（全年）**：

```text
生产环境：
  PDF 文件 → pdftotext → 文本窗口 → OpenAI/Claude 文本 API → JSON → DB
  截图/图片 → 对象存储 → URL 展示（聊天/论坛/认证）
  ≠ 任何 Gemini Vision API
```

## 七、预计不会交付的结果（边界清单）

2026 年末 **预计不会出现** 以下状态（除非改走情景 H/V 且专项批准）：

- [ ] 生产环境 **Gemini Vision** 默认解析用户上传的 PDF/截图  
- [ ] **ModalityService** 对用户 SLA 承诺  
- [ ] 公布的 **「字段抽取准确率 ≥ X%」**（无 gold 全集）  
- [ ] 公布的 **「预测准确率 ≥ X%」**（verified <50）  
- [ ] **作品集视觉质量分** 或作品集录取概率  
- [ ] 用平台用户 outcome **自动校准** per-school multiplier（ADR-0020 禁止）  
- [ ] 多引擎融合概率作为 **served** 主路径回归  
- [ ] 240 校 **100%** 官方源、零启发式（不现实）  
- [ ] Tier1 CDS 分格 **>30 校**（数据获取结构限制）

## 九、对外叙事预计（2026 全年可用）

**可以说的：**

- 录取概率来自 **可引用的公开数据 + 可回放规则**，每条 modifier 可追溯。  
- 覆盖 **240+** 所美国本科目标校的核心指标；对数据缺失显式标注。  
- AI 顾问基于 **文本大模型** 与工具链，辅助选校、文书与档案分析。  
- 内部 CDS 自动化抽取作业成功率约 **八成**（运维口径，非录取准确率）。

**不能说的：**

- 「我们用 **Gemini / GPT-5 Vision** 读你的材料算录取率。」  
- 「预测准确率 **达到 X%**。」  
- 「**AI 评估作品集** 录取可能性。」  
- 「比 CollegeVine 更准」（无同源 benchmark）。

## 十一、假设与刷新

**本预计依赖：**

1. 继续执行 ADR-0020（不用平台样本校准概率）。  
2. 无强制「2026 必须上线 Gemini Vision」的外部里程碑。  
3. 工程资源 **≥1 FTE** 持续投入数据与预测，而非全员做 MMFM。  
4. 2026 申请季末有一定 outcome 自报（Mar–May 窗口）。

**建议每季度刷新：** verified 数、Tier1 校数、`_meta` success rate、heuristic 校数（SQL + `pnpm audit:coverage` 类脚本）。
